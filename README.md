## 线路实测：电信联通走 CN2 GIA，移动是 CMIN2

商家宣传口径写的是“三网回程 CN2 GIA”。2026 年 10 月的一份第三方路由实测给出了更具体的答案，原话是：

> 因此，本次检测到的线路为电信、联通 CN2 GIA，移动 CMIN2，并非三网全部经过 CN2 GIA。

路由细节对得上：北京电信 AS4809 → AS4847，北京联通 AS4809 → AS4134 → AS4837 → AS4808；上海电信 AS4809 → AS4812；广东电信 AS4809 → AS4134 → AS58466。移动三地统一走 AS58807 → AS9808，接入中国移动自己的骨干，不经过 AS4809。

**CN2 GIA 是什么。** 它是中国电信国际出口里最高一档的线路，走 59.43 网段，独立物理路径、跳数更少、优先级更高。普通线路走 202.97 段，晚高峰容易拥堵，表现是打开后台要转圈、SSH 敲一个字符等半秒。买这类套餐，付的钱主要买的就是这一段路。

**延迟数据。** 同一份实测里，TCP 大包测得的延迟是：北京三网约 149ms，上海三网 125～137ms，广东三网 153～164ms，三地三网之间差距不大。另一个较早的测评给圣何塞的平均延迟是约 168ms，没写明测法，两个数字口径不同，可以一起看，不必强行合并成一个。

对移动用户来说，CMIN2 也是优质线路，只是等级和 CN2 GIA 不是一回事。如果你的访问者以电信、联通为主，这条线路的表现符合预期；如果团队里全是移动宽带，别按“三网全 GIA”去预期。

## 下单前要知道的三件事

**一、不保证美国原生 IP，且不能因此退款。**

实测分配到的测试 IP 属于美国广播 IP，注册地显示在澳大利亚，IPinfo、ipregistry、ipapi、IP2Location 都识别为美国，使用类型是机房 IP。官方政策写明不保证美国原生 IP，测试 IP 和实际分配 IP 不一定在同一网段；服务条款不允许以“分配 IP 并非原生 IP”为理由申请退款。

IP 风险评分的分化也值得看：IP2Location 3 分、Scamalytics 0 分、AbuseIPDB 0 分，但 IPQS 给了 75 分并标记为可疑 IP；423 个黑名单库里 421 个正常、2 个已标记。这个组合意味着大部分场景能用，少数对 IP 信誉敏感的服务可能会拦。本地出站 25 端口可用。

**二、流媒体解锁是部分可用。**

同一份实测里，TikTok、YouTube、Amazon Prime Video、ChatGPT 识别为美国区可用；Netflix 只能看美国区自制内容，全区片库不行；Disney+ 和 Reddit 检测为屏蔽。要完整解锁或要住宅 IP 属性的，市面上有专门做双 ISP 家宽住宅 IP 的方案，和这台机器的定位不同。

**三、1GB 内存的真实上限。**

实测机型是 AMD EPYC、1 核 1 线程、Debian 12，Geekbench 5 单核超过 1000 分，内存读写速度不低，15GB SSD 的读写满足轻量建站没问题。但 1GB 内存配 15GB 硬盘，能跑什么有明确边界：静态站、开了缓存的轻量 WordPress、小型 Node 应用、轻量数据库、Telegram bot 都可以；WooCommerce 这类插件多、查询重的电商程序不要指望。跑 WordPress 就得控插件数量并上缓存，否则内存和硬盘同时吃紧。

服务器是非托管型，系统管理、安全补丁、软件更新都要自己做，换来的是完整 root 权限和更低价格。控制面板是中文本地化，重装系统、重启、流量监控都能自助完成。工单时段是 12:00 到 22:00，工作时间内承诺 24 小时答复、48 小时解决，另有 Telegram 交流群。付款用支付宝最顺。
